# Kodi Arasan M & Srinithi S — Wedding Website

A responsive, animated wedding invitation website using plain HTML, CSS and JavaScript. No build process, framework, API key, or database required.

## Deploy to Vercel

1. Extract the ZIP and upload the `kodi-srinithi-wedding` folder to a GitHub repository.
2. In Vercel, select **Add New → Project**, import that repository.
3. Framework preset: **Other**. Build command: leave blank. Output directory: leave blank (project root).
4. Click **Deploy**.

Alternatively, run `npx vercel` in the project folder and follow the prompts.

## Test locally

Open `index.html` in a browser or run `python -m http.server 8000` in the project folder and visit http://localhost:8000.
